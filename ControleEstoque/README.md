📦 Controle de Estoque – Console Application

Sistema de controle de estoque desenvolvido em C#, permitindo o cadastro, atualização, listagem e remoção de produtos, com persistência de dados em arquivo JSON, simulando um CRUD completo.

---

🛠️ Tecnologias Utilizadas
- C#
- .NET Console Application
- Serialização JSON
- Programação Orientada a Objetos (POO)
- Git e GitHub

---

📌 Funcionalidades
- Cadastrar produto (Nome, Código, Quantidade, Preço)
- Listar produtos cadastrados
- Atualizar dados de um produto
- Remover produto do estoque
- Salvar dados automaticamente em arquivo JSON

---

📂 Estrutura do Projeto
- Models → Entidades do sistema
- Services → Regras de negócio e manipulação de dados
- Program.cs → Menu principal e interação com o usuário
